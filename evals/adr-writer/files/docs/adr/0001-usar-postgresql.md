# ADR-0001: Usar PostgreSQL como banco principal

- **Status:** Aceito
- **Data:** 2026-10-01
- **Decisores:** Time

## Contexto
Precisamos de um banco relacional.

## Decisão
Usar PostgreSQL.

## Alternativas consideradas
- **MySQL:** descartado por falta de experiência do time.

## Consequências
- **Positivas:** SQL robusto.
- **Negativas / custos:** operação própria.
- **Riscos e gatilho de revisão:** custo de hospedagem.
